HOSTEL MANAGEMENT PROJECT

1. Open hostel.sql in MySQL Workbench and run it (lightning bolt).
2. In app7.js, change password: "root" to your actual MySQL root password if different.
3. Open terminal in this HostelManagement folder.
4. Run: npm install
5. Run: node app7.js
6. Open Chrome: http://localhost:3000

Fields: roomid, roomname, block, capacity, status.
Status options: Available, Occupied, Maintenance.
Use http://localhost:3000, not Live Server, so backend CRUD works.
